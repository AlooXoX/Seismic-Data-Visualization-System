Mini guía de SQL

  • SELECT — qué columnas quieres ver. * significa “todas”.
  • FROM — de qué tabla vienen los datos.
  • WHERE — filtra filas (por ejemplo, magnitud > 7).
  • JOIN ... ON — une tablas usando sus columnas id_*.
  • GROUP BY con COUNT / SUM / AVG — agrupa y resume.
  • ORDER BY y LIMIT — ordena y limita el número de filas.
